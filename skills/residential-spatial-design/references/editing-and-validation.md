# 编辑与验证规范

## 数据与编辑枢轴

每件资产维护稳定 ID、所属空间、所属方案、原始变换和当前变换。选择对象使用方案加资产 ID 或对象引用，避免同名家具跨方案串联。固定建筑指纹在家具编辑前后保持一致。

优先在生成资产时建立正确局部原点。若需重设枢轴，保持各子件世界变换不变，且只规范化一次；不要每次选择都重新套父组。枢轴规范化在开始记录编辑历史前完成。撤回操作不能把旧父坐标系的快照应用到新父坐标系。

历史按方案隔离，记录一次完整拖动前后的资产变换；选择和切换工具不进入撤回栈。若支持三维旋转，保存完整四元数而非单一欧拉角。恢复时包括位置、旋转和尺度。新编辑清空重做；Ctrl+Z 撤回，Ctrl+Y 与 Ctrl+Shift+Z 重做。

默认移动仅 X/Z 平面，保持原高度；旋转仅绕 Y 轴。隐藏轴还需禁用自由旋转环、屏幕空间环及自由中心手柄，避免绕过约束。Shift 15°、Ctrl 45°吸附可作为默认；释放或窗口失焦清理修饰键状态。显示实际角度或增量，避免用户凭目测判断。

操控器命中优先于家具选取。拖操控器时暂停镜头 Orbit，结束后恢复；不能同时选择背后的另一件家具。区分短点击和镜头拖动，点击空白取消选择。切换风格、关闭设计层、进入漫游或销毁 Viewer 时清理选中对象和相关事件。

## 黑色剖切面

根据真实建筑几何与切平面的交集封口；门窗洞不应被虚假切面覆盖。切面只出现在确实被切到的实体，不悬浮于矮墙上方。封口必须与全局裁剪策略兼容，不能把黑面本身裁掉。取消剖切时隐藏，切换白模或材质时保持黑色。避免滑块每次变化遗留几何和材质。

## 行为验收

在 BASE 与至少两套方案中，选择两件远离原点的家具：分别移动、旋转 45°及90°，交替撤回和重做。确认高度不变、家具不倾倒、不跳位、另一件家具和建筑不变。切换方案再切回，检查历史和资产归属。点击空白隐藏操控器；镜头拖动与家具拖动互不抢占。

在门洞高度以下、窗洞中部、过梁和墙顶附近观察黑色剖切；核对矮墙、柱垛和洞口。检查固定机位不穿墙，Style 切换保持镜头，Arctic 下三套家具仍具有形态差异。实际浏览器测试不可用时记录限制，不声称已通过交互验收。

## 性能

保持单件家具可寻址；可合并家具内部静态网格或共享几何，避免把全屋家具合为不可编辑实体。分别测量初次加载、方案切换、拖动及漫游性能。按设备调整面数、像素比、阴影与 AO；旧验证数据不能作为修改后性能证据。
