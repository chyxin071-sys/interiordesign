# 住宅空间设计 Viewer

固定建筑空间 + 三套可整体替换的全屋设计。按用户最新要求，本阶段只提供交互模型，不提供 Render 或 AI 效果图。

## 使用
先选 BASE / STYLE 01 / STYLE 02 / STYLE 03，再选空间机位。切换方案保留镜头。ARCTIC 隐藏材质而保留家具几何；SHADED 为纯色；MATERIAL 显示程序材质。支持透视、轴测、俯视、二维平面、漫游、旋转/平移/缩放、门扇、剖切、顶面、空间名称、交通动线及原图叠加。光影面板包含四个预设和六项控制。设计方案中点击家具即可选择，W 进入水平移动，R 进入水平旋转，Shift 吸附 15°，Ctrl 吸附 45°，Ctrl+Z 撤回，Ctrl+Y 恢复，点击空白处或 Esc 取消选择；墙体、门窗和固定构件保持不可编辑。可导出当前方案分层 GLB，或保存模型画面 PNG。

## 建筑修正与推断
泳池和庭院为露天空间，已删除误加玻璃。健身区保留跑步机与力量器械，按与庭院、泳池连续的露天平台建模并删除顶面；东侧与公共前室、南侧与住宅的原有边界保留。健身区顶面未标注，露天属于本轮推断。

主入户门连接前室与玄关，向左餐厅、向下客厅；厨房南侧横向过道连接西侧卧室区。主卧套区连接衣帽间与主卫；次卧（二）入口在西北侧。客厅与多功能区不加隔墙。厨房保持湿区与灶具点位。粗黑线按墙体，局部加厚按柱垛占位，不判断承重；右上井道按电梯推定，楼梯为示意，不支持跨层行走。

原图无尺寸、标高、比例尺和朝向。暂用 0.014 m/像素，参考常见床长估算；图示范围约 16.4 × 16.3 m。墙高 2.8 m、门高约 2.15 m、窗台 0.18 m、窗顶 2.65 m、楼板厚 0.16 m、池深 1.2 m 均暂定。原图上方不表示北。弧形窗带由细分折线表达。本模型用于空间与方案比较，非实测 BIM 或施工图。

## 三套完整方案
- STYLE 01 中古现代：圆臂三座沙发、双泡单椅、石面木翼茶几、圆桌、木质靠背椅、阅读工作区。胡桃木、暖白织物、纸灯、陶器、黑皮革与植物。
- STYLE 02 包豪斯趣味现代：绗缝直排沙发、钢管椅、双层玻璃推车、实体穿孔凳、蓝色长桌、钢管床。浅木、镀铬、原色色块、几何地毯与分层吊灯。
- STYLE 03 现代简约高级：不对称模块沙发、脚踏、三件圆茶几、酒红旋转椅、锥形桌底、宽软包床头。浅石、烟熏木、黑金属、细织物和克制重音。

三套均覆盖客餐厅、厨房、三卧、衣帽间、两卫、玄关、多功能区、收纳、健身、庭院与泳池。细节包括分件、倒角、支腿、扶手、柜门和把手；软装包括包边靠垫、几何褶皱披毯、床尾毯、分层床品、连续褶皱窗帘、书籍、陶器、摆台、毛巾、植物及艺术品。均为三维几何，家具为参考设计语言下的中等精度表达，并非品牌产品的精确数字复刻。

## 分层与性能
01_ARCHITECTURE_FIXED 包含墙、柱垛、楼板、顶面、门窗、池体、楼梯及固定点位，三套共用同一几何。02_INTERIOR_DESIGN_REPLACEABLE 包含家具、柜体、饰面、灯具、织物、装饰、植物、器械及户外家具，整层独立生成和缓存。03_REVIEW_ANNOTATIONS 为检查动线。建筑材质可变，坐标和边界不变。

每套设计约 34–37 万三角面；可移动家具保持独立资产组和元数据，未编辑的静态几何再按需批处理。BASE 有 60 件占位家具。视图静止后暂停重绘，无持续离线渲染任务。

## 验证与交付
node scripts/validate-model.mjs 更新 BASE GLB/JSON，验证有效几何、稳定 ID、门洞与主要空间可达性。node scripts/validate-design.mjs 验证方案几何各异、共享建筑指纹不变、全屋覆盖、通行及 16 个固定机位。通行检查使用 5 像素网格、约 0.168 m 半径，平开门视为开启；Viewer 在关门时另加碰撞。可达性不等同于人体工学或无障碍规范审查。
